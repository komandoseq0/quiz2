# 🧠 Quiz JavaScript

Interaktywny **quiz** stworzony w **HTML, SCSS i JavaScript**, który sprawdza Twoją wiedzę o programowaniu i technologii webowej!  

---

## ✨ Funkcje

- 🚀 Rozpoczęcie quizu przyciskiem **Start**.  
- ❓ Losowe pytania z kilkoma możliwymi odpowiedziami.  
- ✅ Sprawdzanie poprawnych odpowiedzi i liczenie punktów.  
- 🎯 Wyświetlanie podsumowania po zakończeniu quizu z liczbą poprawnych i błędnych odpowiedzi.  
- 🖤 Nowoczesny ciemny design i responsywny układ.

---

## 💻 Technologie

- HTML – struktura strony  
- SCSS – stylizacja i animacje przycisków  
- JavaScript – logika quizu, liczenie punktów i wyświetlanie pytań
